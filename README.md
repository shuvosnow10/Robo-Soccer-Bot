🤖 Robo Soccer

A custom-built Robo Soccer designed and developed for robotic competition.

⚙️ Hardware

- ESP32
- BTS7960 Motor Drivers
- 500 RPM Metal Gear Motors
- 3S Li-Po Battery
- 65mm Wheels

🚀 Features

- High-speed movement
- Wireless control
- Four-wheel drive
- Custom-built chassis
